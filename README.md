# Aynam ✦

### AI Communication Studio

Aynam is a calm, personalized AI communication studio designed to help people become clearer, more confident, and more intentional speakers through deliberate practice.

Instead of treating communication as a collection of tips, Aynam turns it into a measurable practice loop:

**Practice → Speak → Analyze → Reflect → Improve**

> Aynam is not an interview-preparation platform.
> It is a general communication practice environment for anyone who wants to communicate better.

## The Problem

Most communication tools give users generic advice:

- "Speak more clearly."
- "Reduce filler words."
- "Be more confident."
- "Practice regularly."

But advice alone doesn't create improvement.

People need a system that lets them:

1. Practice speaking in a low-pressure environment.
2. See what actually happened during their speech.
3. Understand recurring communication patterns.
4. Receive meaningful feedback.
5. Practice again with a specific next focus.

Aynam was built around this idea.

---

## The Product

Aynam provides a focused environment for communication practice.

### Practice

Choose a topic, select a practice duration, and respond naturally.

The experience is intentionally designed to feel more like a personal studio than a traditional learning dashboard.

### Live Speaking

During a session, Aynam captures the user's speech and builds a live transcript.

The session tracks:

- elapsed time
- speaking time
- words spoken
- speech pace
- sentence behavior
- filler words

### AI Review

After a session, Aynam analyzes the response and provides feedback around communication quality.

The review combines deterministic speech analytics with AI-generated qualitative feedback.

### History

Every completed practice session can be stored and revisited later.

Users can review:

- previous sessions
- transcripts
- communication metrics
- feedback
- session-specific patterns

### Insights

Aynam turns individual sessions into longer-term communication insights.

The Insights experience is organized around:

- My Communication
- Patterns
- Progress
- Recommendations

The goal is not to overwhelm users with analytics, but to surface patterns that are actually useful for improving communication.

### Themes

Aynam includes a multi-theme visual system.

Themes change the application's semantic color system while preserving the same underlying product experience.

The design system uses separate:

- primary colors
- secondary accents
- soft surfaces
- borders
- text hierarchy

so themes don't simply become "the same UI with a different button color."
